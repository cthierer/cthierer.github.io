During my internship at Aquilent, I worked with another intern to design and build a **Java EE web application**. The role introduced me to professional software development practices, including code review, version control, structured implementation, and working within an established development lifecycle.

One of the most memorable moments was my first code review. My manager, three full-time engineers, and I sat in a room with my code projected on the wall and talked through it together. It was stressful, but also enlightening, and it gave me an early appreciation for the value of thoughtful peer review.

The internship also gave me experience across the application stack, from application code and data access to the systems and processes used to build maintainable software.
